## 📌 Sobre Este Repositório

Este repositório foi criado para documentar e organizar toda a minha jornada de aprendizado técnico. Aqui reúno anotações teóricas, comandos, resumos de aulas e relatórios de laboratórios práticos realizados no **Cisco Networking Academy**, na comunidade **Mulher Digital / Mulheres em Tech** e em estudos autônomos.
