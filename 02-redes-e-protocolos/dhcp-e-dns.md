# ⚙️ Serviços Essenciais: DHCP e DNS

## 📍 DHCP (Dynamic Host Configuration Protocol)
Serviço responsável pela atribuição automática de endereços IP para os dispositivos da rede.
* **Processo DORA:**
  1. **Discover:** O cliente busca um servidor DHCP.
  2. **Offer:** O servidor oferece um IP.
  3. **Request:** O cliente solicita o IP oferecido.
  4. **Acknowledge:** O servidor confirma a atribuição.

## 🔍 DNS (Domain Name System)
Funciona como a "agenda telefônica" da internet, traduzindo nomes de domínio em endereços IP.
* **Exemplo:** `google.com` ➔ `142.250.190.46`
