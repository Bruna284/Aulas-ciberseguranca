# 🌐 Modelos de Rede: OSI e TCP/IP

## 📚 Comparativo de Camadas

| Camada OSI | Função Principal | Equivalente TCP/IP |
| :--- | :--- | :--- |
| **7. Aplicação** | Interface direta com o usuário (HTTP, DNS) | Aplicação |
| **6. Apresentação** | Formatação e criptografia de dados | Aplicação |
| **5. Sessão** | Gerenciamento de conexão entre aplicações | Aplicação |
| **4. Transporte** | Controle de fluxo e erros (TCP / UDP) | Transporte |
| **3. Rede** | Endereçamento lógico e roteamento (IP) | Internet |
| **2. Enlace** | Endereçamento físico (MAC) e quadros | Acesso à Rede |
| **1. Física** | Transmissão de bits (Cabos, Wi-Fi) | Acesso à Rede |
